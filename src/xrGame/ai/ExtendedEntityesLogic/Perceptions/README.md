# Perceptions

Переиспользуемые механизмы восприятия для Ground, Flying и будущих категорий. Это общие реализации через композицию, а не базовые классы для наследования категориями. Знания и сроки памяти остаются индивидуальными.

Планируемые файлы:

- `CELSharedMemory.h/.cpp` — общая реализация памяти без наследования; знания индивидуальны; [ENTITY].
- `CELSharedHearing.h/.cpp` — общая обработка звуков, используется через композицию; [ENTITY].
- `CELSharedTargets.h/.cpp` — общие операции с индивидуальными целями; композиция; [ENTITY].
- `CELSharedEnemySharing.h/.cpp` — общая доставка и ограничения обмена; [ENTITY].
- `CELSharedPerceptionProfiles.h/.cpp` — независимые правила передачи и слежения; [INIT/READ].

Статус: проектирование; C++-файлы пока только запланированы. Контракты и правила: [план архитектуры](../../../../../doc/extended-entityes-architecture.md).
