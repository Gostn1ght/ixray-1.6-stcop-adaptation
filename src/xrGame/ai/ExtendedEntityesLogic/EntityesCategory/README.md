# EntityesCategory

Реализации категорий расширенной логики. Все реальные категории подключаются одинаково: игра → TExtendedEntityesLogic → IELLogic. Внутренние алгоритмы различаются, внешний конвейер остаётся общим.

Подкаталоги: `Ground/`, `Flying/`, `ExampleCategoryTemplate/`.

Статус: проектирование; C++-файлы пока только запланированы. Контракты и правила: [план архитектуры](../../../../../doc/extended-entityes-architecture.md).
