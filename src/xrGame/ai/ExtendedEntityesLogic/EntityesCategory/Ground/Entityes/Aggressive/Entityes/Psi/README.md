# EntityesCategory/Ground/Entityes/Aggressive/Entityes/Psi

Пси-группа наземных боевых компонентов. Использует общие службы памяти, доставки сообщений и бюджеты. Передача через препятствия и живое слежение задаются независимо профилем вида.

Планируемые файлы:

- `CELBurer.h/.cpp` — наследует CELGroundAttackBase; компонент для CBurer; [ENTITY].
- `CELController.h/.cpp` — наследует CELGroundAttackBase; компонент для CController; [ENTITY].
- `CELPoltergeist.h/.cpp` — наследует CELGroundAttackBase; компонент для CPoltergeist; [ENTITY].
- `CELPsyDog.h/.cpp` — наследует CELGroundAttackBase; компонент для CPsyDog; [ENTITY].
- `CELPsyDogPhantom.h/.cpp` — наследует CELGroundAttackBase; компонент для CPsyDogPhantom; [ENTITY].

Статус: проектирование; C++-файлы пока только запланированы. Контракты и правила: [план архитектуры](../../../../../../../../../../doc/extended-entityes-architecture.md).
