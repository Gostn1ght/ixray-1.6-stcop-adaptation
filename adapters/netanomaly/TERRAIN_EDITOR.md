# Terrain Editor (NetAnomaly SDK)

Отдельный редактор рельефа локации: создаёшь плоскость, лепишь рельеф кистями,
раскрашиваешь слоями текстур и одной кнопкой открываешь результат в Level Editor.

Исходники: `src/Editors/TerrainEditor`. Собирается в CI вместе с остальным SDK
(`TerrainEditor.exe` в пакете NetAnomaly-SDK).

## Первая версия

**Проект рельефа** (`rawdata\terrain\<имя>.terrain`)
- Размер стороны в метрах и разрешение сетки (129…1025 вершин на сторону).
- Высоты в метрах (float на вершину).
- До 4 слоёв текстуры: имя слоя, цвет превью, детальная текстура, вес на вершину.

**Кисти** (левая кнопка мыши — рисовать, колесо с Ctrl — радиус)
- Поднять / Опустить, Сгладить, Выровнять (по высоте точки начала мазка), Шум.
- Слой 1…4 — рисование веса слоя.
- Радиус (м), сила, мягкость края. Undo/Redo по мазкам.

**Экспорт** (`Файл → Экспорт`)
- `rawdata\objects\levels\<имя>\<имя>_terrain.object` — меш рельефа
  (шаг экспорта 1/2/4, UV на всю площадь, поверхность с выбранным шейдером
  `levels\*`, материал `materials\earth`).
- `gamedata\textures\terrain\terrain_<имя>.dds` — базовый цвет (смесь слоёв).
- `gamedata\textures\terrain\terrain_<имя>_mask.dds` — маска слоёв RGBA.
- `.thm` для обеих текстур.

**Открыть в Level Editor** (`Файл → Открыть в Level Editor`)
- Экспорт, затем запуск `LevelEditor.exe -scene <имя>.level -add_object levels\<имя>\<имя>_terrain`.
- Level Editor открывает сцену (или создаёт новую), ставит рельеф и сохраняет сцену.

## Дальше (после первой версии)

- Импорт/экспорт карты высот (r16/png) и импорт из существующего `.object`.
- Дыры в рельефе, кисть «дорога/сплайн», отдельные детальные текстуры на слой.
